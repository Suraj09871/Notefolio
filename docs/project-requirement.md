# NoteFolio Project Requirements Document (PRD)

*Refer to [docs/project-requirements.md](project-requirements.md) for the full detailed specification.*

## Summary Requirements
1. **Frontend:** Pure HTML5, CSS3, ES6+ Vanilla JavaScript.
2. **Backend:** Node.js + Express REST API (`server/`).
3. **Database:** MongoDB Atlas with Mongoose ODM.
4. **Cloud Storage:** Cloudinary for PDF & cover image storage.
5. **Authentication:** Local JWT + Google OAuth 2.0.
6. **Deploy Targets:** Render (Full-Stack Express) & Netlify (Static CDN + Serverless Functions).
7. **Expiry & Deletion:** 6-Month validity policy & self-service library note deletion.
